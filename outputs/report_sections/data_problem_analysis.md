## Problem statement for non-experts

- We observe each user's **historical interactions** (a time-ordered list of item IDs they engaged with).
- **Task:** predict the **single next item** the user will interact with (leave-one-out: the last item of each user is held out as the test target).
- **Crucially**, this is *not* the easy "pick 1 out of ~100 sampled negatives" setup. Evaluation is **full-ranking**: the model must rank the one correct item against the **entire catalog of tens of thousands of items**.
- Therefore **Recall@10 is naturally low**: the model must place the exact held-out item inside the top 10 out of the whole catalog. Recall@10 = 0.04 means ~4% of users get their true next item into the top 10 under this strict exact-match, full-catalog setting.

## Why the problem is hard

1. **Large item catalog** — tens of thousands of candidate items; the model ranks the true item against all of them.
2. **Sparse interactions** — density is a tiny fraction of a percent; most user×item pairs are never observed.
3. **Long-tail item distribution** — a small head of popular items dominates, leaving most items with very few interactions (high Gini), so tail items are hard to learn and to recommend.
4. **Exact next-item prediction** — leave-one-out gives exactly one correct held-out item per user; similar items get no partial credit.
5. **Short histories** — many users have very few interactions, giving the model little signal per user.
